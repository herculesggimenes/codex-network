codex-network: cross-environment control plane

A small local helper lets engineers address conversations and localhost services by stable ids and names, while the implementation stays scoped to Codex app-server, SSH tunnels, and local registry files.

Parent machine

codex-network CLI

Public interface: conversation id, node, port, and forward name.

Conversation registry

nodes.tsv maps node names to Codex app-server WebSocket URLs.

HTTP registry

http.tsv stores named forwards and the shared localhost URL.

SSH tunnel controller

tmux owns long-lived ssh -L and ssh -R sessions.

Local scope only

No public ingress, no central server, no new auth model.
